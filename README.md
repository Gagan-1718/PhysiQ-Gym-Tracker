

# PhysiQ — Gym Tracker

PhysiQ is a database-driven gym tracking system that helps users manage workouts, track progress, nutrition, body measurements, and training history.

## Core Features

- Adaptive body-part workout recommendation
- Workout logging
- Sets, reps, and weight tracking
- Automatic PR detection
- Workout volume tracking
- Progression and next-target estimation
- Nutrition and macro tracking
- Body measurement tracking
- Progress photo timeline
- Analytics dashboard
- Exercise library and history

## Tech Stack

- Next.js
- MySQL
- MongoDB
- NextAuth.js / Auth.js

## Core Concept

Instead of following a fixed weekly workout calendar, PhysiQ analyzes the user's actual workout history and recommends the most overdue body part.

**Plan → Train → Record → Analyze → Adapt → Train Again**
